# Manufacturing Intelligence Dashboard

## Project Overview
The Manufacturing Intelligence Dashboard analyzes manufacturing production data to monitor production output, product defects, machine downtime, and machine-level performance.

## Objectives
- Monitor total production and defects.
- Analyze defect rates across machines.
- Identify machines with high downtime.
- Track production trends over time.
- Support data-driven manufacturing decisions.

## Tools & Technologies
- **Power BI** — Dashboard and visualization
- **PostgreSQL** — Data storage and SQL analysis
- **Python** — Data generation, cleaning, and exploratory analysis
- **Pandas** — Data processing

## Key Performance Indicators (KPIs)
- Total Production
- Total Defects
- Defect Rate (%)
- Total Downtime (Hours)
- Machines Monitored

## SQL Analysis
The project includes SQL queries for:
1. Machine performance analysis
2. High-defect machine identification
3. Machine performance ranking
4. Monthly production trends

## Dashboard Features
- Production trend analysis
- Production by machine
- Defect rate by machine
- Downtime by machine
- Machine filtering using a slicer

## Dataset
The project uses a synthetic manufacturing production dataset created for analytical and educational purposes.

## Business Value
The dashboard helps identify production patterns, quality issues, and machine downtime so that manufacturing teams can investigate inefficiencies and make informed operational decisions.
